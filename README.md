Ages

A Minecraft plugin — Pre-Alpha / Proof of Concept

Ages is a Minecraft plugin currently in early development. This release is intended to demonstrate the project's current functionality and gather initial feedback.

Status

Pre-alpha. Features may be incomplete, unstable, or subject to significant changes. This release is intended primarily for testing and evaluation.

Requirements

Minecraft version: 1.21.4
Server software: Paper

Installation
Download the Ages plugin .jar from the project's Releases page.
Place the .jar into your server's plugins folder.
Start or restart the server.
Check the console for startup errors.

See the Known Issues section before using the plugin on an existing world.

Known Issues

This is an early proof-of-concept release.
Features, configuration, and compatibility may change.

Bug Reports and Feedback

Please report bugs, compatibility issues, and suggestions through the repository's Issues tab.

When reporting a bug, include your Minecraft version, server software, Java version, relevant console errors, and steps to reproduce the problem.
